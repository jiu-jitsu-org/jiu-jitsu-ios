# OSS 리액션 스티커 시안

띠 캐릭터 몸(흰 몸 + 검은 띠 + 띠 위 흰 선 눈)에 MY 화면 주짓수 동작 캐릭터의 얇은 팔·다리, 흰 장갑 손, 흰 신발을 붙여
도장에서 쓰는 손짓(노노, 화이팅, 쏘쏘, 탭 등)을 짧은 반복 짤로 만든 시안입니다. 앱 코드에는 아직 들어가지 않았습니다.

## 보는 법

`index.html` 을 브라우저로 엽니다. 한 페이지에 다음이 다 있습니다.

- 캐릭터를 합친 방식 (띠 몸 + 동작 캐릭터 팔다리 + 장갑)
- Gemini로 뽑은 3D 리액션. 2프레임 루프는 두 장을 번갈아 보여 줍니다
- 스타일 비교: 3D 원색 배경, 3D 다이컷 스티커, 플랫 일러스트, 코드로 그린 벡터
- 움직임 연구 16종: `stickers.js` 가 캔버스에 그립니다. 스타일 3안 · 띠 5색 · 속도를 바꿔 볼 수 있습니다
- 앱에 넣은 모습 (댓글 리액션, 기록 완료, 빈 화면)

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 보고 페이지 |
| `stickers.js` | 움직임 연구 엔진. 리액션마다 `f(t)` 가 한 바퀴(0~1) 동안 몸·팔·표정·효과를 돌려줌 |
| `gemini/ref/` | Gemini에 같이 넣은 참고 그림 4장 (띠 몸, 동작 캐릭터 2장, 장갑 손). 모두 앱에 이미 있는 그림 |
| `gemini/web/` | Gemini 결과 1024px JPEG. `-a` 가 첫 프레임, `-b` 가 손 위치만 바꾼 다음 프레임 |
| `gemini/items.js` | 페이지가 읽는 결과 목록 |
| `gemini/prompts.md` | 리액션별 지시문 |

Gemini 원본(2048px PNG, 장당 약 4MB)은 용량 때문에 저장소에 넣지 않았습니다. `gemini/raw/` 에 두고 쓰며 `.gitignore` 로 뺐습니다.

## 주의

- 3D 그림은 Gemini 생성 시안입니다. 오른쪽 아래에 Gemini 표시가 있어 그대로 앱 에셋으로 쓰지 않습니다.
  고른 리액션은 디자이너가 이 그림을 바탕으로 다시 렌더하거나 키프레임으로 씁니다.
- 앱에 넣을 때는 글자를 그림에 굽지 않고, Lottie(이미 `lottie-ios` 사용 중) 또는 짧은 투명 영상으로 만듭니다.
