## 꼭 보셔야 할 것

1. **[고침] A3-1 P0 대회 기록 유실** — MY에서 대회를 추가 · 수정 · 삭제 · 고정 · 순서 바꾸면 들고 있던(낡을 수 있는) 목록으로 서버 목록을 통째로 덮었다. 다른 기기 · 웹 · 쌓인 MY에서 남긴 기록이 지워질 수 있었다. 저장 직전에 다시 받아 그 위에 바꾸도록 고쳤다(웹 경로와 같은 방식). 적대적 리뷰에서 "고정 · 자리 값만 달라도 헛실패" 지적 → 기록을 가리키는 값으로 찾게 보완.
2. **[고침] A1-02 = A5-1 P1** — 홈 글 상세가 전체 화면 모달로 떠 있으면 게스트 로그인 안내 알럿과 로그인 창이 모달 밑에 깔려 안 보였다. 모달 위에 뜨게 고침.
3. **[출시 체크] A1-03 = A7-2** — `AppStoreLink.appID`가 비어 있어 '업데이트가 필요해요'의 [업데이트]가 아무것도 열지 않는다. **dev 서버 최소 버전을 1.0.0보다 올리면 TestFlight 테스터가 막힌다.** App Store Connect Apple ID가 나오면 넣을 것.
4. **[서버 확인] A6-1 / A6-2** — 최애를 '없음'으로 저장하면 요청에서 그 키가 빠진다(null이 아님). 서버가 "빠진 키 = 그대로 둠"이면 최애가 안 지워진다. 또 어느 섹션을 저장하든 프로필 전체 스칼라 값을 함께 보낸다 — 서버가 해당 섹션 값만 반영하는지 확인 필요.
5. **[서버 확인] A4-1 P1** — 마케팅 수신 동의 · 철회 때 처리 결과와 날짜 안내(정보통신망법 제50조 제7항)가 앱에 없다. 서버가 따로 보내는지 확인.

## 출시 (TestFlight) 체크리스트 — 사람 할 일

1. **첫 머지가 Xcode Cloud 첫 실행.** `origin/main`엔 `ci_scripts`·`Package.resolved`가 없다. develop → main 머지 전에 develop으로 워크플로를 수동 실행해 볼 것
2. Xcode Cloud의 Xcode 버전을 로컬과 같은 26.x로 **고정** (경고를 에러로 처리하므로 Latest면 깨질 수 있음)
3. 시크릿 환경 변수 3개(`SECRETS_XCCONFIG_BASE64`, `GOOGLE_SERVICE_INFO_PLIST_BASE64`, `GOOGLE_SERVICE_INFO_DEV_PLIST_BASE64`)
4. Kakao · GoogleSignIn · Pulse가 `branch:` 추적 — 지금은 Package.resolved로 고정돼 안전. 릴리스 직전 `tuist install --update` 금지, 가능하면 tag로 고정
5. dev Firebase(oss-bjj-dev)에 APNs 키 — 없으면 TestFlight 푸시 안 옴
6. `CFBundleVersion` "1" 고정 — 두 번째 업로드에서 번호 충돌 나면 `$(CURRENT_PROJECT_VERSION)`으로
7. dev 서버 최소 버전 1.0.0 유지 (위 3번 항목)
8. 실기기: iPhone SE 2·3세대(375×667, 가장 작은 iOS 26 기기) 포함 — 체크리스트는 findings/A7.md 끝
