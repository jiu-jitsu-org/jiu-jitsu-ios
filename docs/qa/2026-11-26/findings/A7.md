범위: 문구 · 말투 통일 / 실기기 점검 준비 / TestFlight 올리기 준비. 기준 코드 `qa/ios-release-qa` @ b1b40b6. 빌드는 돌리지 않았다(코드·설정 파일만 읽음).

문구 기준은 #400 커밋 `bf9608c`(chore(copy): 앱 오류 · 토스트 문구를 웹과 같은 해요체로 맞춤)을 따른다.
- 해요체. 토스트·한 줄 안내는 **끝 마침표 없음**. '~에 실패했어요' 대신 '~하지 못했어요'. '해주세요'가 아니라 '해 주세요'(띄어 씀).
- 그때 일부러 남긴 곳: 망 끊김 · 시간 초과(그 뒤 85cb70a에서 고침), 관장 사범 인증 · 로그인 · 약관 · 설정 계정 · 비로그인 안내 · 남의 프로필 문구("다른 PR에서 고침"), **띠 · 벨트 용어(확정 전)**. 아래 남은 어긋남 대부분이 이 "다른 PR" 몫인데 아직 안 고쳐졌다.
- 알럿 본문과 여러 문장 설명은 지금 코드에서 대부분 마침표를 찍는다(Splash, AppView, 대회 기록 삭제, 가입 그만두기, 세션 만료 등). 그래서 제안 규칙은 **"토스트·한 줄 안내·버튼 = 마침표 없음, 알럿 본문·여러 문장 설명 = 마침표 있음"**이다.

### 막힐 수 있는 지점 (위험 높은 순)
1. **첫 실행이다.** `origin/main`에는 `ci_scripts/`·`Package.resolved`가 없고 mise 핀도 4.46.1이다. 릴리스 PR(develop → main, 789커밋, 빨리 감기 가능)을 머지하는 순간이 Xcode Cloud가 이 스크립트를 처음 도는 때다. 머지 전에 **develop 브랜치로 같은 워크플로를 수동 실행(Start Build)** 해 보고 들어가길 권함
2. **Xcode Cloud의 Xcode 버전.** 프로젝트는 경고를 에러로 처리한다(`Project.swift:194-195`). 워크플로 환경을 "Latest Release"로 두면 Xcode가 올라갈 때 새 경고로 아카이브가 깨진다 → 로컬과 같은 26.x로 **고정**. `Tuist.swift`는 26·27을 허용
3. **시크릿 환경 변수 3개** `SECRETS_XCCONFIG_BASE64`, `GOOGLE_SERVICE_INFO_PLIST_BASE64`, `GOOGLE_SERVICE_INFO_DEV_PLIST_BASE64` — 하나라도 없으면 `ci_post_clone.sh`가 바로 멈춤. xcconfig 안 URL은 `https:/$()/…` 이스케이프(`Configs/Secrets.xcconfig.example.md`), `DEVELOPMENT_TEAM`이 들어 있어야 서명됨. Beta 아카이브는 **dev** plist를 넣는다(`Project.swift:31-41`) — dev 값이 실제 dev 프로젝트 것인지
4. **브랜치 추적 의존성**(A7-3) — 지금은 잠금 파일로 고정돼 안전. 릴리스 직전에 `tuist install --update`를 돌리지 말 것
