## 실기기에서 확인할 것
- [ ] 대회 수정 화면에서 비행기 모드로 '완료' → 화면이 남고 토스트, 망을 켜고 다시 '완료' → 닫히고 "대회 정보를 수정했어요"
- [ ] 대회 탭 '결과 남기기' 배너가 보이는 상태에서 MY 탭 → 자동완성으로 그 대회 기록 추가 → 대회 탭으로 돌아가면 배너가 닫혀 있는지
- [ ] MY › 커뮤니티 활동 → 대회가 붙은 글 → 대회 카드 → 끝난 대회 상세의 '내 기록에 남기기' → 기록 추가가 그 위에 쌓이고 저장 · 뒤로가기가 되는지
- [ ] 설정에서 카메라 끔 → 관장 사범 인증 → 사진 업로드 → 카메라 → 알럿 → [설정으로 가기]가 이 앱 설정으로 가는지
- [ ] 느린 망(Very Bad Network)에서 로그아웃 → 덮개가 뜨고 끝나면 게스트 MY + "로그아웃했어요"
- [ ] 반려 사유가 긴 테스트 계정으로 SE에서 인증 시트 — 사유가 다 보이고 버튼이 가리지 않는지
